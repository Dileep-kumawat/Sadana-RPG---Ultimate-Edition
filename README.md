# Sadhana RPG — Ultimate Edition

A standalone HTML/CSS/JS gamified dashboard for your Sadhana routine.

## Features
- Daily quest board with XP
- Mantra Meditation as the highest-value quest (200 XP)
- Combo bonuses and Sacred Combo
- Lifetime levels every 5,000 XP
- Separate Mantra and Sadhana streaks
- Weekly boss battles
- Achievements / badges
- Weekly self-vs-self leaderboard
- Daily chest tiers
- LocalStorage persistence
- Optional sound feedback
- Responsive mobile layout
- No build step and no backend required

## Run
Open `index.html` in a modern browser.

Your progress is saved locally in the browser via localStorage.

## Notes
The page imports Google Fonts when internet access is available; it still works without them using system fallbacks.
